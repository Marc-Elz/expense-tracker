# Expense Tracker

A single-page app to log, categorise, filter, sort and summarise personal expenses. Data is kept in the browser (localStorage), there is no backend.

Built with Claude Code as an agentic coding exercise: the spec and task list it worked from are in [context.md](context.md) and [tasks.md](tasks.md). It has unit tests for the composables.

## Tech stack

Vue 3, TypeScript, Vite, Vitest, ESLint, Prettier

## Getting started

Requires Node.js.

```bash
cd app
npm install
npm run dev
```

Run the tests with `npm test`.
